# 남한고 주변 측정 지도 - 기능 추가본

남한고 중심 250m 지도에서 위치를 선택한 뒤, 측정 요청을 보내거나 밝기 숫자를 직접 저장할 수 있습니다.

## 추가한 기능

- 지도 위치 선택 후 **측정 요청**: ESP32 연결을 위한 기존 요청 방식
- 지도 위치 선택 후 **직접 입력**: 밝기 숫자를 입력하여 그 위치에 저장
- 요청 및 측정 기록마다 **삭제** 버튼 제공. 확인 후 해당 기록 1건과 연결된 측정값만 삭제합니다.
- 기존 데이터베이스에 `brightness` 열을 자동으로 추가합니다. 기존 기록은 삭제하지 않습니다.
- 삭제 API는 별도 키로 보호합니다.

## GitHub에 업데이트하기

이미 Render에 Blueprint를 만들기 전이라면, 아래 파일들을 GitHub 저장소의 기존 파일과 바꿔서 커밋하세요.

- `app.py`
- `render.yaml`
- `templates/index.html`
- `static/style.css`
- `requirements.txt`

`README.md`와 `.gitignore`도 새 파일로 추가/교체할 수 있습니다. `measurement.db`, 비밀번호, API 키는 GitHub에 올리지 마세요.

기존 Blueprint가 아직 생성되지 않았다면 업데이트 커밋 후 Render에서 **New → Blueprint**로 진행하면 됩니다. 이미 Blueprint를 생성했다면 Render가 GitHub 변경을 읽어 자동 동기화할 수 있습니다. 동기화 전 서비스 설정과 비용을 확인하세요.

## Render 배포 후

`render.yaml`이 `DELETE_API_KEY`를 자동 생성합니다. 기록 삭제 버튼을 누르면 이 키를 입력해야 합니다. Render 서비스의 **Environment** 화면에서 `DELETE_API_KEY` 값 표시/복사 기능을 사용해 입력하세요. 키는 공유하거나 GitHub에 올리지 마세요.

ESP32 API는 이전과 같이 `DEVICE_API_KEY`로 보호됩니다.

## 로컬에서 실행하기

Windows CMD에서 프로젝트 폴더로 이동한 뒤:

```cmd
py -m pip install -r requirements.txt
py app.py
```

브라우저에서 `http://127.0.0.1:5000`을 엽니다. 로컬 삭제 확인창에는 `local-delete-key`를 입력하면 됩니다. 이 키는 로컬 실행에서만 쓰이며 Render에서는 사용되지 않습니다.

## 사용 순서

1. 지도에서 반경 안의 지점을 누릅니다.
2. **측정 요청**을 누르면 기존 ESP32 측정 대기 요청이 등록됩니다.
3. **직접 입력**을 누르면 밝기 입력칸이 나타납니다. 0 이상의 숫자를 입력하고 **저장**을 누릅니다.
4. 기록 목록에서 항목을 누르면 지도의 해당 점으로 이동합니다. 오른쪽 **삭제**를 누르면 해당 기록 하나를 확인 후 지웁니다.

밝기 값의 단위는 아직 정하지 않았으므로 입력 숫자를 그대로 저장하고 표시합니다.
